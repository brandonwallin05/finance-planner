# finance-planner

Tool for individuals and groups to create budgets and track finances.



## Project Ideas



* Ability to add sources of income (one-time or repetitive)
* Ability to add expenses (one-time or repetitive)
* Ability to display certain items as family or as individuals
* GUI with pie charts
* Ability to create budgets for set amount of time

  * Ability to use prior budget as "template"
